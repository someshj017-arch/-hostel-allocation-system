# Hostel Room Allocation Management System

A full-stack Database Management System project built with Python (Flask) and MySQL. 

## Features
- Transactional room allocation (prevents double-booking).
- Real-time room availability dashboard.
- Admin view to track student allocation history.
- Strict database constraints (Foreign Keys, CHECK constraints).

## Tech Stack
- **Backend:** Python, Flask
- **Database:** MySQL
- **Frontend:** HTML/CSS (Jinja2 templates)

## How to Run
1. Clone the repository.
2. Run `pip install flask mysql-connector-python`.
3. Update the database credentials in `app.py`.
4. Run `python app.py`.
